# Тесты YAxUnit для 1С

`bsl-unit-test` — навык для помощников с поддержкой [Agent Skills](https://agentskills.io/).
Он помогает создавать, проверять и исправлять тесты BSL на YAxUnit:
выбирать проверки, готовить данные, подменять зависимости и изолировать состояние.

Навык содержит инструкции, справочные материалы и шаблоны. Для работы с ним
нужен помощник с доступом к исходникам проекта 1С. Для выполнения созданных тестов
в проекте должны быть подключены YAxUnit и настроен запуск на платформе 1С.

## Быстрое начало

1. [Установите навык](docs/installation.md) в каталог навыков своего помощника.
   Скопируйте весь каталог репозитория под именем `bsl-unit-test`.
2. Убедитесь, что помощник видит навык, и откройте свой проект 1С.
3. Укажите метод и ожидаемое поведение, например:

   > Используй навык bsl-unit-test. Покрой тестами метод Расчеты.СуммаСкидки.
   > Исходники находятся в открытом проекте. При сумме 100 и скидке 25 процентов
   > ожидается 75. Используй существующее расширение с тестами.

Помощник должен изучить метод и соседние тесты, подготовить изменение и сообщить,
что удалось проверить. Фактическое выполнение в 1С указывается отдельно.

Установка навыка не подключает YAxUnit к информационной базе и не настраивает
средства запуска тестов.

## Установка через помощника

Если помощник умеет устанавливать навыки из репозиториев, передайте ему:

> Установи навык bsl-unit-test из https://github.com/Sejix/bsl-unit-test
> для текущего проекта. Инструкции установки находятся в docs/installation.md,
> а SKILL.md лежит в корне репозитория.

Для закрытого репозитория потребуется предоставленный доступ к GitHub.
Ручная установка, команды, обновление и устранение проблем описаны в
[инструкции установки](docs/installation.md).

## Возможности и совместимость

- Проверки значений, коллекций, исключений и изменений информационной базы.
- Регистрация тестов, варианты параметров, подготовка и очистка данных.
- Мокито, подготовленные перехватчики `&Вместо`, заглушки HTTP и ADO.RecordSet.
- Создание и исправление тестов с учетом формата исходников и контекста выполнения.

Навык не требует конкретной конфигурации, БСП, Unica или других навыков.
Для работы достаточно файлов навыка; Python нужен только для проверки самого
репозитория. Дополнительный файл `agents/openai.yaml` содержит описание для Codex.

Примеры программного интерфейса сверены с исходниками YAxUnit **25.12**.
Это основа проверки, а не требование обновить проект до этой версии.
Для других версий помощник должен подтвердить нужные методы в целевом проекте.
Источники и ограничения: [совместимость](references/compatibility.md).

## Проверка качества

Из корня репозитория выполните:

```text
python -X utf8 scripts/validate.py
```

Нужен Python 3.9 или новее, дополнительные пакеты не требуются.
Программа проверяет локальные ссылки, сценарии и заполнение шаблонов.
Формат Agent Skills дополнительно проверяется средством `skills-ref`;
установка и команды приведены в [памятке участникам](CONTRIBUTING.md).
В GitHub Actions подготовлены эти проверки для Linux и Windows.

Статическая проверка не подтверждает качество ответов помощника и выполнение
тестов в 1С. Сценарии оценки находятся в [evals/README.md](evals/README.md),
сведения о предыдущей проверке — в [evals/validation.md](evals/validation.md).

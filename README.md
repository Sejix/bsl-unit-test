# Навык для написания тестов YAxUnit

`bsl-unit-test` помогает создавать, дополнять, проверять и исправлять модульные тесты на BSL для YAxUnit в 1С:Предприятии.

## Когда применять

Используйте навык, если нужно:

- покрыть экспортный метод модульными тестами;
- подготовить проверку результата или исключения;
- применить параметризованные сценарии;
- настроить Мокито или перехват `&Вместо`;
- проверить изменения в информационной базе;
- подготовить тестовые данные, HTTP- или SQL-заглушки.

## Содержимое

- `SKILL.md` — основной порядок работы и правила выбора стратегии тестирования;
- `references/` — справочные материалы по утверждениям, Мокито, перехватам, вариантам, данным и распространенным ошибкам;
- `assets/` — шаблоны тестового модуля и заимствованного модуля;
- `evals/` — сценарии проверки качества навыка.

## Основной подход

1. Прочитать тестируемый метод и необходимые зависимости.
2. Выбрать простейшую подходящую стратегию.
3. Подготовить штатный, граничный, невалидный и ошибочный сценарии.
4. Добавить тест в существующий модуль либо создать его из шаблона.
5. Зарегистрировать процедуру в `ИсполняемыеСценарии()`.

Подробные инструкции, включая правила для сложных сценариев, находятся в [SKILL.md](SKILL.md).

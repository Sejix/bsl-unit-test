# `ЮТест.Данные()`, builders и генераторы

Используй этот файл, когда тесту нужны не самодельные структуры, а готовые
генераторы YAxUnit.

Всегда входи через `ЮТест.Данные()`. Не обращайся к модулю
`ЮТТестовыеДанные` напрямую.

## Что брать первым

- Для примитивов и случайных значений: `СлучайноеЧисло`,
  `СлучайнаяСтрока`, `СлучайнаяДата`, `СлучайноеЗначениеИзСписка`,
  `СлучайноеЗначениеПеречисления`, `Подражатель()`.
- Когда нужна только ссылка нужного типа, а наполнение не важно:
  `СоздатьЭлемент(...)`, `СоздатьДокумент(...)`.
- Когда нужен реальный объект ИБ с контролируемыми реквизитами:
  `КонструкторОбъекта(...)`.
- Когда нужны движения документа:
  `КонструкторДвижений(...)`.
- Когда тестируешь SOAP/XML/XDTO:
  `КонструкторОбъектаXDTO(...)`.

## `КонструкторОбъекта(...)`

Используй `КонструкторОбъекта(...)`, если:

- тесту действительно нужен объект ИБ;
- важно провести, записать или заполнить табличные части;
- ручная подготовка реквизитов получается длиннее и менее читаемой.

```bsl
Документ = ЮТест.Данные().КонструкторОбъекта("Документы.ПриходТовара")
	.ФикцияРеквизитов("Поставщик, Склад")
	.ФикцияОбязательныхПолей()
	.ТабличнаяЧасть("Товары");
```

### `Фикция*`

`Фикция`, `ФикцияРеквизитов` и `ФикцияОбязательныхПолей` используй, чтобы:

- не расписывать несущественные реквизиты вручную;
- выделить важные для теста поля;
- сократить boilerplate.

Если тест проверяет конкретный реквизит, задавай его явно через
`.Установить(...)`, а не оставляй на случайную фикцию.

## `КонструкторДвижений(...)`

Бери `КонструкторДвижений(...)`, если нужно подготовить движения документа, а
не вручную формировать наборы записей регистра.

## Когда builder не нужен

- Для чистой логики без ИБ чаще достаточно `Структура`, `Массив`,
  `ТаблицаЗначений` и приемов из `references/fixtures.md`.
- Если метод только читает несколько полей из объекта, не тащи в тест
  полноценный документ ради одного свойства.

## Клиент и сервер

Где возможно, используй строковое имя объекта метаданных. Это упрощает вызов
с клиента:

```bsl
ЮТест.Данные().КонструкторОбъекта("Справочники.Товары")
```

## Не делай так

- Не пиши длинные фабрики тестовых данных вручную, пока не проверил
  `ЮТест.Данные()`.
- Не используй случайные данные для значений, которые тест должен проверять
  точно.
- Не создавай записи в ИБ, если тесту нужна только типизированная ссылка или
  in-memory структура.

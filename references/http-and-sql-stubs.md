# HTTP и ADO: готовые заглушки

Источники: [средства подмены](https://bia-technologies.github.io/yaxunit/docs/features/mocking/),
обработки `ЮТHTTPСервисЗапрос`, `ЮТHTTPОтвет`, `ЮТHTTPСоединение`, `ЮТRecordSet`
[проверенной версии](compatibility.md).

Это обработки с похожим интерфейсом, а не экземпляры встроенных типов платформы
или COM-объекты. Если код проверяет точный тип, требует неподдерживаемый метод
или передает объект в типизированный интерфейс, проверь совместимость отдельно.
Не обещай полную подстановку по одному сходству названий.

## Входящий HTTP-запрос

```bsl
Запрос = ЮТест.Данные().HTTPСервисЗапрос()
	.УстановитьТелоКакСтрокуJSON(Новый Структура("Ключ", "Значение"))
	.ДобавитьЗаголовок("Content-Type", "application/json")
	.ДобавитьПараметрЗапроса("режим", "проверка");
```

В 25.12 конструктор доступен на сервере. Передай объект в существующую точку
обработки запроса и проверь код, заголовки и содержимое ответа по задаче.
Не разворачивай веб-публикацию для проверки доступного обработчика. Если обработчик
недоступен из теста, сначала исследуй точки вызова; перенос прикладного кода
в общий модуль не является обязательной частью написания теста.

## Исходящее соединение и ответ

```bsl
Ответ = ЮТест.Данные().HTTPОтвет()
	.УстановитьКодСостояния(200)
	.УстановитьТело("Готово");

Соединение = ЮТест.Данные().HTTPСоединение().УстановитьHTTPОтвет(Ответ);
```

В 25.12 оба конструктора серверные. `УстановитьТело(...)` принимает строку или
двоичные данные, а не произвольную структуру. JSON сначала сериализуй готовым
средством проекта. Соединение нужно внедрить через параметр или существующий
метод-фабрику с подготовленным перехватчиком. Создание этой переменной не подменяет
`Новый HTTPСоединение` внутри проверяемого кода.

Для ответа с ошибкой задавай соответствующий код и тело. Для ошибки транспорта
есть `HTTPСоединение().ВыброситьИсключение(Текст)`; проверь момент срабатывания
в нужной версии. Выбирай только существенные сценарии: успешный ответ, ожидаемая
ошибка сервиса, неверное содержимое или ошибка транспорта.

## ADO.RecordSet

```bsl
Набор = ЮТест.Данные().ADORecordSet("Код,Цена")
	.Добавить("Т001", 100)
	.Добавить("Т002", 250);
```

Эмулятор предоставляет `Fields()`, `MoveFirst()`, `MoveNext()`, `EOF()` и другие
операции. В 25.12 доступен на сервере и в толстом клиенте обычного приложения.
Подготовь также пустой набор, если проверяемый код должен его обрабатывать.
Не подменяй им `ВыборкаИзРезультатаЗапроса` или обычную таблицу, если нужен
именно такой платформенный тип.

## Прочие средства

Документация сайта описывает также сообщения сервиса интеграции. Проверь наличие
конструктора и его интерфейс в установленной версии: для 25.12 пример не заявлен.
Если готовая заглушка не подходит, объясни конкретно отсутствующее поведение
и только затем используй собственную минимальную реализацию.

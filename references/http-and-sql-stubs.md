# `HTTPСервисЗапрос()` и `ADORecordSet()`

Используй этот файл, когда тесту нужны платформенные объекты интеграции, а не
самодельные структуры.

## `ЮТест.Данные().HTTPСервисЗапрос()`

Бери `HTTPСервисЗапрос()`, когда тестируемый код ожидает настоящий
`HTTPСервисЗапрос` и работает с телом, заголовками или query-параметрами.

```bsl
Запрос = ЮТест.Данные().HTTPСервисЗапрос()
	.УстановитьТелоКакСтрокуJSON(Новый Структура("Ключ", "Значение"))
	.ДобавитьЗаголовок("Content-Type", "application/json");
```

Практические правила:

- если тестируется бизнес-логика HTTP-метода, выноси ее в общий модуль и
  тестируй модуль, а `HTTPСервисЗапрос()` используй как входной объект;
- если код читает тело как строку или двоичные данные, используй встроенные
  методы объекта, а не самодельные реквизиты структуры;
- если нужен только payload, не строй полноценную веб-публикацию.

## `ЮТест.Данные().ADORecordSet(...)`

Бери `ADORecordSet(...)`, когда код ожидает `ADO.RecordSet` и читает его через
`Fields()`, `MoveFirst()`, `MoveNext()`, `EOF()` и подобный API.

```bsl
RecordSet = ЮТест.Данные().ADORecordSet("ID,Наименование,Цена")
	.Добавить(1, "Товар1", 100.50)
	.Добавить(2, "Товар2", 250.00);
```

Практические правила:

- передавай колонки строкой в том порядке, в котором их читает тестируемый код;
- используй `Добавить(...)` для строк данных вместо самодельных таблиц и
  структур;
- если код работает не с `ADO.RecordSet`, а с обычной `ТаблицаЗначений`,
  `ADORecordSet(...)` не нужен.

## Когда брать эти stubs, а не Мокито

Предпочитай built-in stub, если метод тестируется по поведению объекта:

- читает тело HTTP-запроса;
- читает заголовки или query-параметры;
- двигает курсор `RecordSet`;
- читает `Fields(n).Value`.

Предпочитай Мокито, если нужно только подменить внешний вызов другого модуля,
а не эмулировать сам платформенный объект.

## Не делай так

- Не подменяй `HTTPСервисЗапрос` или `ADO.RecordSet` структурой "на глаз".
- Не строй собственный fake-API, если YAxUnit уже дает объект с нужным
  контрактом.
- Не используй эти stubs там, где достаточно простых in-memory данных из
  `references/fixtures.md`.

# Утверждения YAxUnit для `bsl-unit-test`

Используй этот файл как основной справочник по обычным assertions. Источник
сигнатур в текущем репозитории:

- `CommonModules/ЮТУтверждения/Ext/Module.bsl`

Все проверки вызываются через `ЮТест.ОжидаетЧто(Значение)`.

Для проверок наличия данных в ИБ читай отдельный
`references/db-assertions.md`.

## Значения и типы

```bsl
ЮТест.ОжидаетЧто(Результат).Равно(Ожидаемое);
ЮТест.ОжидаетЧто(Результат).НеРавно(НеОжидаемое);
ЮТест.ОжидаетЧто(Флаг).ЭтоИстина();
ЮТест.ОжидаетЧто(Флаг).ЭтоЛожь();
ЮТест.ОжидаетЧто(Значение).Заполнено();
ЮТест.ОжидаетЧто(Значение).НеЗаполнено();
ЮТест.ОжидаетЧто(Значение).ЭтоНеопределено();
ЮТест.ОжидаетЧто(Значение).ЭтоНеНеопределено();
ЮТест.ОжидаетЧто(Значение).ИмеетТип("Строка");
ЮТест.ОжидаетЧто(Значение).НеИмеетТип("Число");
```

## Числа, даты, строки, коллекции

```bsl
ЮТест.ОжидаетЧто(Число).Больше(0);
ЮТест.ОжидаетЧто(Число).БольшеИлиРавно(0);
ЮТест.ОжидаетЧто(Число).Меньше(100);
ЮТест.ОжидаетЧто(Число).МеждуВключаяГраницы(1, 10);

ЮТест.ОжидаетЧто(Строка).Содержит("подстрока");
ЮТест.ОжидаетЧто(Строка).НачинаетсяС("префикс");
ЮТест.ОжидаетЧто(Строка).ЗаканчиваетсяНа("суффикс");

ЮТест.ОжидаетЧто(Коллекция).ИмеетДлину(3);
ЮТест.ОжидаетЧто(Коллекция).ИмеетДлинуБольше(0);
ЮТест.ОжидаетЧто(Коллекция).Содержит(Элемент);
```

Для `ДвоичныеДанные` не используй `.ИмеетДлину*()`. Проверяй тип и размер
отдельно:

```bsl
ЮТест.ОжидаетЧто(Данные).ИмеетТип("ДвоичныеДанные");
ЮТест.ОжидаетЧто(Данные.Размер()).Больше(0);
```

## Свойства и цепочки

```bsl
ЮТест.ОжидаетЧто(Структура).Свойство("ИмяПоля").Равно(Значение);
ЮТест.ОжидаетЧто(Структура).ИмеетСвойство("ИмяПоля");
ЮТест.ОжидаетЧто(Коллекция).Элемент(0).Свойство("Наименование").Равно("Первый");
ЮТест.ОжидаетЧто(Структура)
	.Свойство("Поле")
	.Равно(1)
	.Объект()
	.Свойство("ДругоеПоле")
	.Равно(2);
```

Используй `.Объект()`, а не `.Родитель()`.

## Исключения

`ВыбрасываетИсключение` в текущем YAxUnit требует первый аргумент. Если нужно
проверить любое исключение, передай пустую строку.

```bsl
ЮТест.ОжидаетЧто(Модуль)
	.Метод("ИмяМетода", ЮТМетоды.МассивПараметров(П1, П2))
	.ВыбрасываетИсключение("");

ЮТест.ОжидаетЧто(Модуль)
	.Метод("ИмяМетода", ЮТМетоды.МассивПараметров(П1))
	.ВыбрасываетИсключение("часть текста");

ЮТест.ОжидаетЧто(Модуль)
	.Метод("ИмяМетода", ЮТМетоды.МассивПараметров(КорректныйПараметр))
	.НеВыбрасываетИсключение();
```

Если проверяешь исключение метода объекта, синтаксис тот же:

```bsl
ЮТест.ОжидаетЧто(СправочникОбъект)
	.Метод("Записать")
	.ВыбрасываетИсключение("");
```

## Параметры метода и предикаты

```bsl
ЮТМетоды.МассивПараметров(П1, П2, П3);

ЮТест.ОжидаетЧто(Объект)
	.Метод("ИмяМетода")
	.Параметр(Значение1)
	.Параметр(Значение2)
	.НеВыбрасываетИсключение();
```

Для сложных условий используй предикаты:

```bsl
Предикат = ЮТПредикаты
	.Реквизит("Сумма").Больше(0)
	.И()
	.Реквизит("Статус").Равно("Активен");

ЮТест.ОжидаетЧто(Объект).СоответствуетПредикату(Предикат);
ЮТест.ОжидаетЧто(Коллекция).КаждыйЭлементСоответствуетПредикату(Предикат);
```

## Быстрые правила выбора

- Булевы результаты проверяй через `.ЭтоИстина()` и `.ЭтоЛожь()`.
- Для структур и объектов проверяй отдельные свойства, а не весь объект целиком.
- Для коллекций сначала фиксируй длину, потом содержимое.
- Для строки с частично известным содержимым используй `.Содержит()`.
- Для любого исключения используй только `.ВыбрасываетИсключение("")`.
- Если одна и та же проверка повторяется на наборе входов, переходи к
  `references/variants.md`.

# Утверждения и предикаты

Источники: [утверждения](https://bia-technologies.github.io/yaxunit/docs/features/assertions/),
[исходники проверенной версии](compatibility.md).

## Значение и наблюдаемое поведение

Вход в проверки - `ЮТест.ОжидаетЧто(ФактическоеЗначение, Описание)`;
описание необязательно и помогает различить варианты сценария.

```bsl
ЮТест.ОжидаетЧто(Результат).Равно(75);
ЮТест.ОжидаетЧто(Флаг).ЭтоИстина();
ЮТест.ОжидаетЧто(Значение).ЭтоНеопределено();
ЮТест.ОжидаетЧто(Значение).ИмеетТип("Строка");
ЮТест.ОжидаетЧто(Число).МеждуВключаяГраницы(1, 10);
ЮТест.ОжидаетЧто(Текст).Содержит("Готово");
ЮТест.ОжидаетЧто(Коллекция).ИмеетДлину(2);
```

Выбирай проверку, которая отличает нужный результат от ошибки. Одна проверка
`Заполнено()` вместо точной суммы или отсутствие исключения вместо записи
не подтверждают требуемое поведение. `Равно()` умеет сравнивать составные значения;
используй сравнение целиком, если важен весь состав, или отдельные свойства,
если несущественные поля могут меняться.

Для двоичных данных проверяй `Размер()`, не предполагай поддержку `ИмеетДлину()`.
Для параметров по ссылке проверяй требуемую замену значения, для изменяемого
объекта - его состояние независимо от наличия `Знач` в параметрах.

## Свойства и цепочки

```bsl
ЮТест.ОжидаетЧто(Данные).ИмеетСвойство("Сумма");
ЮТест.ОжидаетЧто(Данные).Свойство("Сумма").Равно(75);
ЮТест.ОжидаетЧто(Данные).Свойство("Статус").Равно("Готово");
```

В 25.12 `Свойство(...)` выбирает свойство исходного объекта, а не предыдущего
выбранного свойства. Для вложенного значения указывай путь, например
`Свойство("Адрес.Город")`, или начни отдельное утверждение для вложенного объекта.
Не предполагай, что `.Элемент(0).Свойство("Имя")` означает вложенный переход.
`Объект()` возвращает проверку к исходному объекту после выбора свойства.

## Исключения

В 25.12 первый параметр `ВыбрасываетИсключение` обязателен. Пустая строка
означает любое исключение; фрагмент сообщения помогает проверить нужную причину.
Проверка любого исключения может скрыть ошибку подготовки или перехвата.

```bsl
ЮТест.ОжидаетЧто(ПроверяемыйМодуль)
	.Метод("ПроверитьВход", ЮТМетоды.МассивПараметров(НеверноеЗначение))
	.ВыбрасываетИсключение("Обязательное значение");
```

`ПроверяемыйМодуль` - условный модуль с экспортным методом `ПроверитьВход`.
Для метода объекта синтаксис тот же. Метод вызывается самим утверждением;
не выполняй его заранее и повторно, особенно если он меняет состояние.
`НеВыбрасываетИсключение()` уместен, когда отсутствие ошибки и есть проверяемое
требование; в остальных случаях дополни проверкой результата или изменений.

Исключения после записи в базу требуют учета состояния транзакции:
см. [изоляцию](lifecycle.md). Не перехватывай исключение собственной проверки
вместе с ожидаемым исключением проверяемого кода.

## Предикаты

Начинай через `ЮТест.Предикат()`. Последовательные условия объединяются;
завершай конструирование `Получить()`, чтобы сохранить набор до создания другого.

```bsl
Условие = ЮТест.Предикат()
	.Реквизит("Сумма").Больше(0)
	.Реквизит("Статус").Равно("Готово")
	.Получить();

ЮТест.ОжидаетЧто(Данные).СоответствуетПредикату(Условие);
ЮТест.ОжидаетЧто(Коллекция).КаждыйЭлементСоответствуетПредикату(Условие);
```

Не обращайся к модулю предикатов без инициализации и не добавляй методы,
название которых лишь кажется естественным. Для проверки записей базы
используй [соответствующую справку](db-assertions.md).

# Минимальные данные и платформенные объекты

Выбирай минимальный объект, который сохраняет существенное для сценария поведение.
Для готовых конструкторов см. [создание данных](test-data-builders.md),
для объектов со своими методами - [заглушки](http-and-sql-stubs.md).

## Структуры и коллекции

Если проверяемый код только читает поля, часто достаточно структуры:

```bsl
Контекст = Новый Структура("Ключ, Разрешено", "Проверка", Истина);
```

Когда код читает `Данные.Поле`, соответствие не является равноценной заменой.
Если проверяется тип, методы объекта, запись или обработчики объекта, структура
тоже не воспроизводит требуемый интерфейс. Не подменяй предмет проверки.

Для проверки замены параметра, переданного по ссылке, подготовь исходное значение
и проверь его после вызова. Например, если метод должен заменить таблицу ее строкой:

```bsl
Таблица = Новый ТаблицаЗначений;
Таблица.Колонки.Добавить("Значение");
Строка          = Таблица.Добавить();
Строка.Значение = "Первая";

Данные = Таблица;
```

Проверяй не только тип нового значения, но и значимые данные строки. Для таблицы
сохраняй обычную серверную доступность этого типа; не переноси пример в тонкий
клиент без проверки.

## Информация об ошибке

`ИнформацияОбОшибке` получается из обработчика реального исключения:

```bsl
СведенияОбОшибке = Неопределено;

Попытка
	
	ВызватьИсключение "Тестовая ошибка";
	
Исключение
	
	СведенияОбОшибке = ИнформацияОбОшибке();
	
КонецПопытки;
```

## Выборка без прикладных записей

```bsl
Выборка       = (Новый Запрос("ВЫБРАТЬ 1 КАК Значение")).Выполнить().Выбрать();
ПустаяВыборка = (Новый Запрос("ВЫБРАТЬ 1 КАК Значение ГДЕ ЛОЖЬ")).Выполнить().Выбрать();
```

Такая выборка не зависит от данных справочников, но требует работающего окружения
1С и выполнения запроса в допустимом контексте. Это не способ исполнить запрос
вне информационной базы. Учти положение курсора до и после вызова метода.

## Реальные объекты в памяти

Незаписанный объект или набор записей полезен для проверки заполнения. Создание
через менеджер, добавление строк и проверка полей не равны записи в базу.
Однако учти вызываемые обработчики заполнения и другие зависимости конкретного
объекта: отсутствие явного `Записать()` не доказывает отсутствие обращений к базе.

Константы, перечисления и предопределенные данные выбирай из текущей конфигурации.
Чтение константы зависит от состояния базы. Если значение влияет на ветвление,
задай его контролируемо с восстановлением или используй точку подмены проекта;
не считай значение по умолчанию универсальным основанием теста.

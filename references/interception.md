# `&Вместо`: перехват, self-call и заимствование

Используй этот файл, когда нужен `&Вместо`, а не только Мокито.

Если Мокито решает задачу сам, не усложняй тест перехватчиком.

## Мокито-интегрированный stub

Канонический паттерн:

```bsl
&Вместо("ВыполнитьМетодКонфигурации")
Процедура Расш_ВыполнитьМетодКонфигурации(Знач ИмяМетода, Знач Параметры = Неопределено)
	ПараметрыМетода = Мокито.МассивПараметров(ИмяМетода, Параметры);
	ПрерватьВыполнение = Ложь;
	Результат = МокитоПерехват.АнализВызова(
		ОбщегоНазначения, "ВыполнитьМетодКонфигурации", ПараметрыМетода, ПрерватьВыполнение);
	Если НЕ ПрерватьВыполнение Тогда
		ПродолжитьВызов(ИмяМетода, Параметры);
	КонецЕсли;
КонецПроцедуры
```

Что это дает:

- Мокито управляет поведением через `Обучение(...).Когда(...)`;
- `Мокито.Проверить(...).Вызовы("...")` получает реальные параметры вызова;
- без инструкции Мокито `ПродолжитьВызов(...)` оставляет реальное поведение.

## Self-call

Если метод `A()` вызывает экспортный метод `B()` того же модуля, и `B()`
небезопасен для юнит-теста:

- добавь `&Вместо("B")` в расширение того же модуля;
- внутри stub используй `МокитоПерехват.АнализВызова`;
- не рассчитывай, что `Мокито.Обучение(Модуль).Когда("B").Пропустить()`
  само перехватит self-call.

Тот же прием нужен, если после Act ты хочешь получить реальные параметры через
`Мокито.Проверить(...).Вызовы(...)`.

## Заимствование стороннего модуля

Когда надо перехватить экспортный метод нетестируемого модуля:

1. Создай borrowed-описание модуля по шаблону
   `assets/adopted-common-module.xml.template`.
2. Добавь только нужный `&Вместо`-stub в
   `CommonModules/<ИмяМодуля>/Ext/Module.bsl`.
3. Добавь `<CommonModule>ИмяМодуля</CommonModule>` в `Configuration.xml`.

Если нужен больше чем один новый перехватчик в чужом модуле, сначала изложи
план пользователю.

## Глобальные функции платформы

`ТранзакцияАктивна()`, `ТекущаяДата()` и аналогичные глобальные функции не
принадлежат модулю. Их нельзя перехватить ни Мокито, ни `&Вместо`.

Управляй состоянием напрямую:

```bsl
НачатьТранзакцию();
Модуль.Метод();
ОтменитьТранзакцию();
```

## Минимальный критерий готовности stub

- есть `&Вместо("ИмяМетода")`;
- параметры собраны в `Мокито.МассивПараметров(...)`;
- вызван `МокитоПерехват.АнализВызова(...)`;
- при `НЕ ПрерватьВыполнение` выполняется `ПродолжитьВызов(...)`.

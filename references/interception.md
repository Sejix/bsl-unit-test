# Перехватчики для Мокито

Источник: [подготовка Мокито](https://bia-technologies.github.io/yaxunit/docs/features/mocking/mockito/).
Шаблоны соответствуют [проверенной версии](compatibility.md).

## Найти или подготовить

Сначала найди существующий перехват нужного метода. Проверь имя, владельца,
сигнатуру, сторону выполнения и вызов `МокитоПерехват.АнализВызова`.
Не создавай дублирующий обработчик. Количество новых перехватчиков не требует
отдельного согласования само по себе; учитывай фактические границы задачи.

Если перехвата нет, заимствуй объект конфигурации и нужный метод в тестовое
расширение средствами проекта. Не считай произвольную ручную правку XML
универсальным способом: для EDT и Конфигуратора метаданные различаются.
Проверяемый объект и сигнатуру бери из текущих исходников, не из примера.

Мокито управляет перехватом и для вызова `A()` -> `B()` внутри того же модуля.
Не заменяй тестируемый `A()` целиком, если проверяется его собственная логика.
Доступный для расширения неэкспортный `B()` тоже может быть точкой подмены;
экспортность нужна для прямого вызова из другого модуля, а не как общее условие
существования перехватчика. Ограничения зависят от объекта и платформы.

## Процедура и функция

Готовые заготовки:

- [процедура](../assets/instead-stub.bsl.template);
- [функция](../assets/instead-function.bsl.template).

Процедура пропускает исходный вызов, когда Мокито обработал его; иначе вызывает
`ПродолжитьВызов(...)`. Функция в обработанной ветви возвращает результат Мокито,
в необработанной - результат `ПродолжитьВызов(...)`. Потеря `Возврат` меняет
поведение даже при выключенной подмене.

Сохраняй порядок параметров, `Знач`, значения по умолчанию и соответствующие
директивы. Массив аргументов и аргументы продолжения должны описывать одну и ту же
сигнатуру. Для метода без параметров можно передать `Новый Массив`.
Служебные переменные перехватчика не должны совпадать с параметрами метода.

В `АнализВызова` передавай правильного владельца:

| Модуль | Владелец |
|---|---|
| Общий модуль | Сам общий модуль |
| Модуль объекта или набора записей | `ЭтотОбъект` |
| Модуль менеджера | Менеджер соответствующего объекта |

В тесте обучай и проверяй того же владельца. Для объектов и менеджеров уточни
правила сопоставления экземпляров в используемой версии, не подставляй общий
модуль по аналогии.

## Ограничения

Мокито не перехватывает глобальные функции платформы: `ТекущаяДата()`,
`ТранзакцияАктивна()` и подобные вызовы не являются методами конфигурации.
Для транзакции используй [настройки теста](lifecycle.md). Для времени задавай
устойчивые ожидания или используй существующую зависимость проекта; не меняй
системные часы и не добавляй новый прикладной интерфейс без необходимости.

Подмена конструктора платформы также не появляется от вызова `Обучение()`.
Заглушку HTTP-соединения нужно передать в доступную точку внедрения либо вернуть
через перехваченный метод проекта. Если такой точки нет, опиши ограничение
и необходимое изменение, не обещай несуществующую изоляцию.

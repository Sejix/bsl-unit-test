# Параметризованные тесты и `ЮТест.Варианты()`

Используй этот файл, когда несколько сценариев отличаются в основном входными
данными, а не структурой теста.

## Предпочтение по умолчанию

Параметризованные тесты через `.СПараметрами(...)` обычно предпочтительнее:

- каждая комбинация параметров попадает в отчет как отдельный тест;
- падение одного набора не маскирует остальные;
- данные видны прямо в `ИсполняемыеСценарии()`.

## Когда брать `.СПараметрами(...)`

Бери `.СПараметрами(...)`, если:

- тестовая процедура уже принимает фиксированный набор параметров;
- количество комбинаций невелико и их удобно перечислить заранее;
- каждая комбинация должна быть отдельной записью в отчете.

```bsl
Процедура ИсполняемыеСценарии() Экспорт

	ЮТТесты
		.ДобавитьТест("ЗначенияРавны")
			.СПараметрами(1, 1, Истина)
			.СПараметрами("1", 1, Ложь);

КонецПроцедуры
```

## Когда брать `ЮТест.Варианты()`

Бери `ЮТест.Варианты()`, если:

- набор сценариев удобнее собрать внутри теста;
- нужно пройтись по метаданным, перечислениям или массивам значений;
- нужны автоматические комбинации через `ДобавитьКомбинации()`;
- достаточно одного экспортного тестового сценария с внутренним циклом.

```bsl
Процедура Менеджер_ВозвращаетНужныйМенеджер() Экспорт

	Варианты = ЮТест.Варианты("Параметр, Результат")
		.Добавить("Справочник.Товары", Справочники.Товары)
		.Добавить(Тип("СправочникСсылка.Товары"), Справочники.Товары);

	Для Каждого Вариант Из Варианты.СписокВариантов() Цикл
		Описание = СтрШаблон("%1 (%2)", Вариант.Параметр, ТипЗнч(Вариант.Параметр));
		ЮТест.ОжидаетЧто(ЮТОбщий.Менеджер(Вариант.Параметр), Описание)
			.Равно(Вариант.Результат);
	КонецЦикла;

КонецПроцедуры
```

## `ДобавитьКомбинации()`

Используй `ДобавитьКомбинации()`, когда реально нужно прогнать декартово
произведение входов. Перед этим зафиксируй размер выборки, чтобы не породить
взрыв числа сценариев.

## Правила выбора

- Один алгоритм, фиксированные кейсы, нужен отдельный отчет по каждому:
  `.СПараметрами(...)`.
- Один алгоритм, кейсы строятся динамически или комбинируются:
  `ЮТест.Варианты()`.
- Если сценарии различаются не только данными, а подготовкой окружения,
  разделяй их на разные тесты, а не прячь в один цикл.

## Не делай так

- Не дублируй десяток почти одинаковых тестовых процедур, если отличается
  только вход и ожидаемый результат.
- Не смешивай `.СПараметрами(...)` и `ЮТест.Варианты()` в одном и том же тесте
  без явной причины.
- Не прячь сложную подготовку окружения в `ЮТест.Варианты()`: это ухудшает
  читаемость и диагностику.

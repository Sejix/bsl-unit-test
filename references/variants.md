# Параметры теста и варианты

Источник: [регистрация](https://bia-technologies.github.io/yaxunit/docs/features/test-registration/),
`ЮТКонструкторВариантов` [проверенной версии](compatibility.md).

## Отдельный результат на каждый набор

Используй `СПараметрами(...)`, если сценарии имеют одинаковую подготовку
и различаются входами и ожиданиями. Каждый набор получает отдельный результат;
ошибка одного набора не прерывает исполнение остальных вариантов теста.

```bsl
// Регистрирует проверки расчета скидки.
Процедура ИсполняемыеСценарии() Экспорт
	
	ЮТТесты.ДобавитьСерверныйТест("СуммаСоСкидкой")
		.СПараметрами(100, 0, 100)
		.СПараметрами(100, 25, 75)
		.СПараметрами(100, 100, 0);
	
КонецПроцедуры
```

Тестовая процедура `СуммаСоСкидкой` должна принимать три параметра. Указанные
значения служат примером данных, а не требованием к реализации прикладного метода.
Неправильные типы, пустые значения и отрицательные числа добавляй только
в рамках подтвержденных требований к проверяемому методу.

В регистрации допустимы до десяти параметров, пригодных для передачи движком.
Несериализуемые значения и объекты с изменяемым состоянием создавай внутри теста
по простому описанию варианта. Не создавай записи базы в `ИсполняемыеСценарии()`.

## Варианты, собираемые во время исполнения

`ЮТест.Варианты("Вход, Ожидание")` удобен, если данные строятся динамически
или нужны комбинации. Он создает набор значений, а не регистрирует отдельные тесты.

```bsl
Варианты = ЮТест.Варианты("Вход, Ожидание").Добавить("", 0).Добавить("абв", 3);

Для Каждого Вариант Из Варианты.СписокВариантов() Цикл
	
	Описание = СтрШаблон("Длина строки: %1", Вариант.Вход);
	ЮТест.ОжидаетЧто(СтрДлина(Вариант.Вход), Описание).Равно(Вариант.Ожидание);
	
КонецЦикла;
```

Это пример обхода конструктора, а не тест прикладной функции. В настоящем тесте
вызывай проверяемый метод и сохраняй независимость данных каждого прохода.
Исключение внутри цикла остановит оставшиеся проверки этой процедуры, поэтому
для независимых результатов предпочитай регистрацию параметров.

`ДобавитьКомбинации(...)` формирует сочетания переданных значений. Оцени количество
до запуска; полное декартово произведение нужно только при соответствующем
требовании. Для различных способов подготовки используй отдельные сценарии.

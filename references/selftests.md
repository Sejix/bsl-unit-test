# Собственные тесты YAxUnit

Эти соглашения действуют в проекте `tests/` репозитория YAxUnit. В прикладном
расширении найди его собственный порядок размещения и регистрации. Общие правила
выбора контекста описаны в [регистрации](registration.md).

## Выбор имени

Сначала найди тесты проверяемого модуля в расширении.
Для нового имени соедини префикс, имя объекта и, когда применимо, суффикс.

| Тип | Префикс | Тип | Префикс |
|---|---|---|---|
| Общий модуль | `ОМ_` | Бизнес-процесс | `БП_` |
| Регистр бухгалтерии | `РБ_` | Регистр накопления | `РН_` |
| Регистр расчёта | `РР_` | Регистр сведений | `РС_` |
| Справочник | `Спр_` | Документ | `Док_` |
| План счетов | `ПС_` | План видов расчёта | `ПВР_` |
| План видов характеристик | `ПВХ_` | План обмена | `ПО_` |
| Перечисление | `Пер_` | Задача | `Зад_` |
| Обработка | `Обр_` | Отчёт | `Отч_` |

У общего модуля имя заканчивается названием проверяемого модуля.
Для объекта используй суффикс `_МО`, для менеджера — `_ММ`, для набора записей —
`_НЗ`. Например, `РС_Настройки_НЗ` проверяет набор записей регистра сведений.
В существующих именах суффикс может быть опущен.

## Добавление модуля

1. Включи новый общий модуль в состав тестового расширения средствами проекта.
   При дополнении существующего модуля сохрани его свойства.
2. У собственных тестов объекта и менеджера YAxUnit включи только серверное выполнение.
   У тестов общего модуля сверь доступность на сервере, в управляемом и обычном
   клиенте со свойствами проверяемого модуля. Для набора записей проверь
   доступность кода и настройки соседних тестов того же типа.
3. Дай экспортной тестовой процедуре имя проверяемого метода. Зарегистрируй её
   в `ИсполняемыеСценарии()`; варианты входов присоединяй вызовами
   `.СПараметрами(...)` к регистрации теста. Описание сценария размещай в самом тесте,
   отдельный файл Markdown для него не нужен.
4. После добавления модуля или набора проверь, какую выборку читает
   `ОМ_ЮТЧитательСлужебный`. Пересчитай ожидание `.ИмеетДлину(...)`, только если
   в эту выборку вошли новые элементы. Проверь и новый тест, и затронутый тест чтения.

Основание — [соглашения о собственных тестах YAxUnit](https://github.com/bia-technologies/yaxunit/blob/a2beee45e81ad1108db3f73aa892fbd7972c2ba6/.agents/skills/yaxunit-selftests-structure/SKILL.md).

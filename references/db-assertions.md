# Assertions ИБ через `ЮТест.ОжидаетЧтоТаблицаБазы(...)`

Используй этот файл, когда тестируемый метод оставляет наблюдаемый след в
информационной базе.

## Когда это основной инструмент

Бери `ЮТест.ОжидаетЧтоТаблицаБазы(...)`, если нужно проверить:

- запись появилась;
- запись не появилась;
- запись появилась по конкретному предикату;
- в базе нет лишних записей по конкретному условию.

```bsl
Условие = ЮТест.Предикат()
	.Реквизит("Артикул").Равно(Артикул)
	.Получить();

ЮТест.ОжидаетЧтоТаблицаБазы("Справочник.Товары")
	.НеСодержитЗаписи(Условие);

СоздатьТовар(Артикул);

ЮТест.ОжидаетЧтоТаблицаБазы("Справочник.Товары")
	.СодержитЗаписи(Условие);
```

## Когда этого недостаточно

Не используй `ОжидаетЧтоТаблицаБазы(...)` для детальной проверки заполнения
созданной записи. Сначала проверь факт существования, затем получи запись и
проверь поля обычными assertions:

```bsl
СозданныйТовар = ЮТЗапрос.Запись("Справочник.Товары", Условие);
ЮТест.ОжидаетЧто(СозданныйТовар)
	.Заполнено()
	.Свойство("Наименование").Заполнено()
	.Свойство("Артикул").Равно(Артикул);
```

Так ошибка будет диагностичнее: отдельно "запись не создана" и отдельно
"запись создана, но заполнена неверно".

## Что проверять до и после Act

- До Act часто полезна проверка `НеСодержитЗаписи(...)`.
- После Act проверяй `СодержитЗаписи(...)` или `НеСодержитЗаписи(...)` в
  зависимости от ожидаемого эффекта.
- Если метод только наполняет набор записей в памяти и не вызывает
  `.Записать()`, assertions ИБ не нужны.

## Доступные короткие проверки

Используй специализированные методы, если они делают тест короче и понятнее:

- `СодержитЗаписиСНаименованием(...)`
- `СодержитЗаписиСКодом(...)`
- `СодержитЗаписиСНомером(...)`
- `НеСодержитЗаписиСНаименованием(...)`
- `НеСодержитЗаписиСКодом(...)`
- `НеСодержитЗаписиСНомером(...)`

## Не делай так

- Не подменяй все проверки ИБ длинными ручными запросами, если нужна только
  проверка существования записи.
- Не проверяй заполнение каждой колонки через `ОжидаетЧтоТаблицаБазы(...)`.
- Не объявляй метод интеграционным только потому, что он пишет в ИБ; сначала
  проверь, решают ли задачу assertions ИБ и обычные assertions.

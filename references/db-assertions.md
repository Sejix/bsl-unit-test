# Проверки информационной базы

Источник: [утверждения базы](https://bia-technologies.github.io/yaxunit/docs/features/assertions/).
Интерфейс сверяется по `ЮТУтвержденияИБ` и `ЮТЗапросы`
[проверенной версии](compatibility.md).

Проверка базы уместна, когда запись - наблюдаемый результат работы. Сначала
определи [изоляцию и очистку](lifecycle.md). Проверка только существования
не доказывает правильность всех полей или отсутствие лишних записей.

Ниже предполагается, что в проверяемой конфигурации есть справочник `Товары`
с реквизитом `Артикул`, а `СоздатьТовар` - проверяемая операция проекта.
Имена метаданных всегда заменяй подтвержденными именами текущего проекта.

```bsl
Условие = ЮТест.Предикат().Реквизит("Артикул").Равно(ТестовыйАртикул).Получить();
ЮТест.ОжидаетЧтоТаблицаБазы("Справочник.Товары").НеСодержитЗаписи(Условие);

СоздатьТовар(ТестовыйАртикул);

ЮТест.ОжидаетЧтоТаблицаБазы("Справочник.Товары").СодержитТолькоОднуЗапись(Условие);
Запись = ЮТЗапросы.Запись("Справочник.Товары", Условие);
ЮТест.ОжидаетЧто(Запись).ЭтоНеНеопределено();
ЮТест.ОжидаетЧто(Запись).Свойство("Артикул").Равно(ТестовыйАртикул);
ЮТест.ОжидаетЧто(Запись).Свойство("Наименование").Равно(ОжидаемоеНаименование);
```

Получай тестовый артикул из контролируемых данных, не полагайся на отсутствие
конкретной строки в чужой базе. Ограничивай проверки и очистку именно созданными
данными. Если важно отсутствие дубликатов, используй `СодержитТолькоОднуЗапись`,
а не получение первой попавшейся записи.

`СодержитЗаписи(Предикат)` допускает проверку значений реквизитов через условия;
запрещать ее для полей оснований нет. Отдельное чтение записи полезно для подробной
диагностики нескольких значений, табличных частей и дальнейших проверок.
Доступны также `НеСодержитЗаписи`, проверки кода, номера и наименования.

Если метод только наполняет набор записей в памяти, проверяй сам набор.
Если он записывает данные, учитывай фактическое взаимодействие с базой независимо
от того, проверяется ли результат запросом или утверждениями YAxUnit.

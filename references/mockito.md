# Мокито: канонический API и паттерны

Источники истины в текущем репозитории:

- `CommonModules/Мокито/Ext/Module.bsl`
- `CommonModules/МокитоОбучение/Ext/Module.bsl`

Используй только современный API `Мокито.Обучение(...).Когда(...)`.

## Базовый синтаксис

```bsl
Мокито.Обучение(Модуль).Когда("ИмяФункции").Вернуть(Значение);
Мокито.Обучение(Модуль).Когда("ИмяПроцедуры").Пропустить();
Мокито.Обучение(Модуль).Когда("Метод").ВыброситьИсключение("текст");
Мокито.Обучение(Модуль).Когда("Метод").ВыполнитьМетод();
Мокито.Обучение(Модуль).Наблюдать("ИмяМетода");

Мокито.Прогон();
```

Допустим и цепочный переход в прогон:

```bsl
Мокито.Обучение(Модуль).Когда("Метод").Пропустить().Прогон();
```

## Параметры вызова

```bsl
Мокито.Обучение(Модуль)
	.Когда("Метод", ЮТМетоды.МассивПараметров("КонкретныйПараметр"))
	.Вернуть(Значение);
```

Для неизвестного точного значения используй предикат:

```bsl
Мокито.Обучение(Модуль)
	.Когда("Метод", ЮТМетоды.МассивПараметров(ЮТест.Предикат().Больше(0)))
	.Вернуть(Значение);
```

## Проверки после Act

```bsl
Мокито.Проверить(Модуль).КоличествоВызовов("ИмяМетода").Заполнено();
Мокито.Проверить(Модуль).КоличествоВызовов("ИмяМетода").Пусто();
Мокито.Проверить(Модуль).КоличествоВызовов("ИмяМетода").Равно(2);
```

Для фактических параметров используй `Вызовы()`, но только если вызов
перехватывается корректным `&Вместо`-stub через `МокитоПерехват.АнализВызова`:

```bsl
Вызовы = Мокито.Проверить(ОбщегоНазначения).Вызовы("ВыполнитьМетодКонфигурации");
ЮТест.ОжидаетЧто(Вызовы.Количество()).Равно(1);
ЮТест.ОжидаетЧто(Вызовы[0].Параметры[0]).Равно("Модуль.Метод");
```

## Когда Мокито достаточно

- зависимость является экспортным методом другого модуля;
- нужно управлять возвратом, исключением или фактом вызова;
- self-call не участвует;
- не нужно перехватывать приватный метод или глобальную функцию платформы;
- тестируемый код не зависит от реального контракта `HTTPСервисЗапрос` или
  `ADO.RecordSet`.

## Когда одного Мокито недостаточно

- нужен self-call экспортного метода того же модуля;
- нужно захватить реальные параметры через `Вызовы()`;
- вызов идет через `&Вместо`-перехватчик в borrowed-модуле.

В этих случаях читай `references/interception.md`.

## Не делай так

- Не используй `Мокито.Обучить(...)` и `ВернутьРезультат(...)`.
- Не пытайся мокировать приватные методы.
- Не забывай перевести Мокито в режим прогона перед Act.
- Не подменяй через Мокито объекты, для которых у YAxUnit уже есть готовые
  stubs в `references/http-and-sql-stubs.md`.

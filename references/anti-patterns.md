# Частые ошибки и `Do / Don't`

Используй этот файл как короткий sanity-check перед сохранением тестов.

## Регистрация тестов

- `Do`: `ЮТТесты.ДобавитьТест(...)`
- `Don't`: `ЮТест.ДобавитьТест(...)`

- `Do`: добавляй каждый тест в `ИсполняемыеСценарии()`
- `Don't`: рассчитывать, что YAxUnit сам найдет незарегистрированную процедуру

- `Do`: объявляй тестовые процедуры и `ИсполняемыеСценарии()` с `Экспорт`
- `Don't`: оставлять их приватными

## Assertions

- `Do`: использовать `.ВыбрасываетИсключение("")` для любого исключения
- `Don't`: вызывать `.ВыбрасываетИсключение()` без аргумента

- `Do`: использовать `.Объект()` в цепочке утверждений
- `Don't`: использовать `.Родитель()`

- `Do`: проверять существование записи через assertions ИБ, а заполнение полей
  через обычные assertions
- `Don't`: смешивать обе задачи в одной проверке ИБ

## Мокирование и перехват

- `Do`: использовать `Мокито.Обучение(...).Когда(...)`
- `Don't`: использовать устаревшее `Мокито.Обучить(...)`

- `Do`: мокировать только `Экспорт`
- `Don't`: пытаться мокировать приватные методы

- `Do`: добавлять `&Вместо` для self-call и для `Вызовы()`
- `Don't`: рассчитывать, что одного Мокито хватит для self-call

- `Do`: использовать `МокитоПерехват.АнализВызова(...)` в `&Вместо`-stub
- `Don't`: проверять `Вызовы()` без корректного stub

## Тестовые данные

- `Do`: сначала проверять `ЮТест.Данные()`
- `Don't`: сразу писать свою фабрику или fake-объект

- `Do`: использовать `HTTPСервисЗапрос()` и `ADORecordSet()`, если код зависит
  от их реального контракта
- `Don't`: заменять их случайной `Структура`

- `Do`: использовать ручные fixtures для чистой логики
- `Don't`: тащить `КонструкторОбъекта(...)` туда, где достаточно
  `Структура` или `ТаблицаЗначений`

# Частые ошибки

Используй справку при проверке или разборе сбоя, а не как обязательный перечень
дополнительных действий для каждого простого теста.

| Признак | Что проверить |
|---|---|
| Процедура не появляется в списке тестов | Экспорт, регистрация через `ЮТТесты`, состав и контекст модуля |
| Записи создаются при загрузке списка тестов | Подготовка ошибочно помещена в `ИсполняемыеСценарии()` |
| Мокито настроен, но выполняется исходный код | Наличие и владелец перехвата, условия и переход в `Прогон()` |
| Пропало предыдущее правило обучения | Повторное `Обучение` того же объекта без `Ложь` |
| Нет вызовов в статистике | Точка входа, сторона исполнения, владелец, фильтры и сброс статистики |
| Функция возвращает `Неопределено` | Перехватчик потерял результат Мокито или `ПродолжитьВызов()` |
| Неэкспортный метод признан неперехватываемым | Не смешаны ли прямой вызов из теста и расширение метода |
| HTTP-заглушка не проходит проверку типа | Обработка YAxUnit не равна встроенному типу платформы |
| Создана заглушка соединения, но идет реальный запрос | Заглушка не внедрена в проверяемый код |
| Проверка исключения проходит из-за ошибки подготовки | Сужение причины исключения и проверка точки вызова |
| Предикат работает непоследовательно | Инициализация через `ЮТест.Предикат()` и сохранение `Получить()` |
| Проверяется не то вложенное свойство | `Свойство()` выбирает путь относительно исходного объекта |
| Записи остаются после теста | Граница транзакции, отслеживание данных, контекст и общая подготовка |
| Тест работает только после другого теста | Неявная зависимость от данных или состояния предыдущего сценария |
| Для проверки типа создан лишний элемент базы | Подходящая ссылка или минимальный объект вместо записи |
| Тест проходит после ослабления ожидания | Проверка все еще должна различать правильный и ошибочный результат |

Не обращайся к несуществующему `ЮТЗапрос.Запись`; в проверенной версии модуль
называется `ЮТЗапросы`. Не используй `И()` у конструктора предиката и другие
неподтвержденные названия по аналогии. Для сигнатур и версий см.
[совместимость](compatibility.md).

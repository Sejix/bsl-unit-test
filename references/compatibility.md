## Существенные уточнения

- Мокито использует подготовленные `&Вместо` для подмены методов и сбора вызовов.
  Это относится и к вызовам других модулей, и к вызовам внутри того же модуля.
- `Обучение(Объект)` сбрасывает настройки **указанного объекта**. Для дообучения
  того же объекта передай `Ложь`; первый вызов для другого объекта этого не требует.
- Для чтения записи используется `ЮТЗапросы.Запись`, не `ЮТЗапрос.Запись`.
- Предикат начинай через `ЮТест.Предикат()` и сохраняй через `Получить()`.
  Для последовательного добавления условий не нужен выдуманный метод `И()`.
- `СоздатьЭлемент` и `СоздатьДокумент` записывают объект. Полученная ссылка
  не является ссылкой на несуществующий объект.
- HTTP-заглушки являются обработками YAxUnit, а не встроенными типами платформы.
  В 25.12 их создание доступно на сервере; `ADORecordSet` также доступен
  в толстом клиенте обычного приложения.
- На сайте есть описание `СообщениеСервисаИнтеграции`; в проверенном выпуске
  соответствующий конструктор в `ЮТТестовыеДанные` не найден. Перед использованием
  установи версию, в которой он доступен; готового примера для 25.12 здесь нет.
- Транзакции доступны не только на сервере, но и в поддерживаемых толстых клиентах.
  Для тонкого клиента нельзя полагаться на них как на способ очистки.

## Основание структуры навыка

Краткое описание назначения, чтение справок по необходимости и отсутствие
произвольных обязательных остановок соответствуют
[рекомендациям OpenAI по обновлению навыков](https://developers.openai.com/blog/rethinking-skills-and-prompts-for-gpt-6-astra).
Качество изменений оценивается на задачах по
[методике проверки навыков](https://developers.openai.com/blog/eval-skills).
Названия моделей не являются условиями работы навыка; результаты сравнения
относятся к конкретному окружению и не доказывают качество на всех моделях.
